# JPMC Task 1
Starter repo for task 1 of the JPMC software engineering program

## LinkedIn Easy Apply Chrome Extension

This repository now includes a Chrome extension for automatically applying to jobs on LinkedIn using the Easy Apply feature.

### Quick Start

1. Navigate to the `linkedin-easy-apply-extension` directory
2. Follow the installation instructions in the [Extension README](linkedin-easy-apply-extension/README.md)
3. Load the extension in Chrome at `chrome://extensions/`

For detailed documentation, see the [Extension README](linkedin-easy-apply-extension/README.md).
