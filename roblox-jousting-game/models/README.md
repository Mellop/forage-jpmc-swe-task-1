# 3D Models Directory

This directory is intended for 3D models used in the Roblox Jousting Game.

## Recommended Models

### Horse Models
- **Horse.rbxm** - Main horse model for players to ride
- **HorseAnimations.rbxm** - Animation sets for horse movement

### Weapon Models
- **Lance.rbxm** - Detailed jousting lance model
- **Shield.rbxm** - Optional shield for defensive gameplay

### Arena Models
- **ArenaWalls.rbxm** - Decorative medieval arena walls
- **Banners.rbxm** - Tournament banners and flags
- **Grandstand.rbxm** - Spectator seating areas

## Model Requirements

- All models should be optimized for Roblox performance
- Use appropriate collision detection settings
- Include proper anchor points for animations
- Consider mobile device limitations for polygon count

## How to Add Models

1. Create your model in Roblox Studio or import from external sources
2. Save as .rbxm or .rbxmx files
3. Place in this directory
4. Reference in the appropriate game scripts using `game:GetService("InsertService"):LoadAsset(assetId)`

## Current Status

⚠️ **This directory currently contains placeholder content.** The game uses basic geometric shapes created programmatically. For a full implementation, detailed 3D models should be added to enhance the visual experience.
