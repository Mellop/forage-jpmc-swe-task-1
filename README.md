# JPMC Task 1 + Roblox Jousting Game
Starter repo for task 1 of the JPMC software engineering program

## Original JPMC Trading Application

This repository contains a Python-based financial trading application with client-server architecture for processing stock market data.

### Files:
- `client3.py` - Trading client application
- `server3.py` - Trading server application  
- `client_test.py` - Unit tests for client functionality
- `requirements.txt` - Python dependencies

## 🎮 NEW: Roblox Jousting Game

A complete medieval jousting game has been added to this repository! Experience multiplayer combat on horseback with lances in a custom arena.

### Quick Start:
```bash
cd roblox-jousting-game/
# See README.md for full setup instructions
```

### Game Features:
- 🏇 Horse-mounted combat with up to 8 players
- ⚔️ Lance combat system with charging mechanics  
- 🏆 Real-time scoring and leaderboards
- 🏟️ Custom medieval arena with spawn points
- 🎨 Complete UI with health bars and charge meters
